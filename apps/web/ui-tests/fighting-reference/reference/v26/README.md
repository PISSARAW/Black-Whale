# Clash · Règles 26

Réenregistrement des 96 flux de commandes d’origine avec les règles courantes
du dépôt, dont les attaches multiples, ancrages, mobilité verticale et rappels
d’objets d’Hisoka. Les paquets de commandes et les états initiaux sont vérifiés ;
les archives précédentes restent conservées.

`baseline.json` donne les empreintes de chaque séquence ; `sources.json` recense
les sources mesurées ; `SHA256SUMS` vérifie l’archive `replays.tar.gz`.
