# Référence de combat 30

Les 96 flux de commandes originaux, rejoués sous `clash-combat-30` : intégration dans
`main` de la [grammaire de combo](../../../../src/lib/fighting/COMBO_GRAMMAR.md) et des
[techniques avancées du Nen](../../../../src/lib/fighting/NEN_COMBAT.md) (`clash-combat-29`),
avec les contrôles mobiles, la navigation et l’Académie déjà présents sur `main`
(`clash-combat-19`). Les archives antérieures restent intactes.

`baseline.json` décrit chaque état initial et final, `replays.tar.gz` contient les
replays avec leurs checkpoints, `sources.json` identifie les sources utilisées et
`SHA256SUMS` permet de vérifier les fichiers archivés.
