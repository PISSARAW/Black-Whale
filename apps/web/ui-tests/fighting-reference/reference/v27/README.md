# Référence de combat 27

Les 96 flux de commandes originaux, rejoués sous `clash-combat-27` : lot 4 de la
[grammaire de combo](../../../../src/lib/fighting/COMBO_GRAMMAR.md). Trente-six
personnages suivent la grammaire à niveaux : cinq réglés à la main, trente et un par
dérivation automatique (`duelComboDerivedGrammar.ts`). Phinks, Leorio, Bonolenov et
Padaille restent hors grammaire. Les archives antérieures restent intactes.

`baseline.json` décrit chaque état initial et final, `replays.tar.gz` contient les
replays avec leurs checkpoints, `sources.json` identifie les sources utilisées et
`SHA256SUMS` permet de vérifier les fichiers archivés.
