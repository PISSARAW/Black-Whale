# Référence de combat 23

Les 96 flux de commandes originaux, rejoués sous `clash-combat-23` : lot 1 de la
[grammaire de combo](../../../../src/lib/fighting/COMBO_GRAMMAR.md). Kurapika et
Benjamin suivent la grammaire à niveaux, avec de nouveaux timings, le damage scaling
à la place de la décroissance du hitstun et le mur réservé aux coups de mise au sol.
50 états finaux changent. Les archives antérieures restent intactes.

`baseline.json` décrit chaque état initial et final, `replays.tar.gz` contient les
replays avec leurs checkpoints, `sources.json` identifie les sources utilisées et
`SHA256SUMS` permet de vérifier les fichiers archivés.
