# Référence de combat 29

Les 96 flux de commandes originaux, rejoués sous `clash-combat-29` : fusion de la
[grammaire de combo](../../../../src/lib/fighting/COMBO_GRAMMAR.md) (`clash-combat-28`,
branche `feat/clash-combo-grammar`) avec les
[techniques avancées du Nen](../../../../src/lib/fighting/NEN_COMBAT.md)
(`clash-combat-24`, branche `fix/arena-replay-ko`). Les deux versions ont évolué en
parallèle ; aucune ne contient l’autre, d’où un nouveau numéro. Les archives
antérieures restent intactes.

`baseline.json` décrit chaque état initial et final, `replays.tar.gz` contient les
replays avec leurs checkpoints, `sources.json` identifie les sources utilisées et
`SHA256SUMS` permet de vérifier les fichiers archivés.
