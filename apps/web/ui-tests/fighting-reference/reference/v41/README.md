# Référence de commandes · clash-combat-41

La chaîne directionnelle de Kurapika et Hisoka modifie la suite possible après deux pressions sur la commande de coup léger. La relance aérienne, les trois autres fins et les vérifications des prérequis passent par les entrées et le moteur de production.

Les 96 flux de commandes historiques ont été réenregistrés avec les mêmes prémisses et les mêmes paquets. Le fichier `baseline.json` conserve leur provenance et leurs empreintes. `SHA256SUMS` protège l’archive et `sources.json` indique les sources de combat mesurées.
