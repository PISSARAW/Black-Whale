# Feitan — gestes contre Zazan

Planche de contrôle du rendu de production, reliée aux
[références et règles du combat](../../src/lib/fighting/FEITAN_COMBAT.md).

`node apps/web/scripts/check-fighting-feitan-combat.mjs` capture douze attaques et
quatre déplacements dans les trois phases et les deux orientations. Le script
exporte six images, les positions de la main et de la pointe, et `report.json`
dans `output/clash-feitan-combat/`. Chrome est requis.
