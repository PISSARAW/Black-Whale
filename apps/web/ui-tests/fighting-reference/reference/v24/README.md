# Référence de combat 24

Ce lot conserve les 96 flux de commandes originaux sous `clash-combat-24`.
Il ajoute les [usages des sept techniques avancées](../../../../src/lib/fighting/NEN_COMBAT.md)
aux réglages des combos déjà archivés dans `v23`. Les archives antérieures
restent intactes ; un ancien replay ne reçoit pas une nouvelle version par
simple changement de son en-tête.

`baseline.json` décrit chaque état initial et final, `replays.tar.gz` contient
les replays avec leurs checkpoints, `sources.json` identifie les sources
utilisées et `SHA256SUMS` permet de vérifier les fichiers archivés.

Les états de Gyo corporel ou faible et de Ko défensif font partie des états
rejoués. Les coûts, répartitions et multiplicateurs sont des réglages arcade,
pas des mesures attribuées au manga. Le On conserve son contrat.
