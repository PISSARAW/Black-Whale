# Kurapika · références de combat

Depuis `apps/web` : `node scripts/check-kurapika-reference.mjs`.
La page `/ui-tests/kurapika-reference/` montre les 14 commandes dans trois phases
et deux orientations, avec les figures, les gestes et les chaînes de production.
La quinzième planche montre une capture obtenue par le moteur sur Phinks,
cible autorisée du roster. Les autres vues échantillonnent les frames des gestes.

Captures et rapport : `output/kurapika-reference/`.
