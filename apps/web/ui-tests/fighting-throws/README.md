# Cinématiques de projection

Depuis `apps/web`, lancer `node scripts/check-fighting-throws.mjs`.
La fixture joue des états issus de vraies commandes de projection dans la scène
de production. Elle contrôle prise, renversement, arrivée au sol, retour au jeu,
P1/P2, déprojection, raté, pause, caméra stable et formats 390/320 px.
Captures et rapport : `/tmp/black-whale-throw-cinematics`.
