# Référence de combat 33

Les 96 flux de commandes originaux, rejoués sous `clash-combat-33` : intégration de
`clash-combat-30` (grammaire de combo, techniques avancées du Nen, contrôles mobiles)
avec les commits arrivés entre-temps sur `origin/main` en `clash-combat-32` (Stealth
Dolphin, Black Voice, Gallery Fake, matière historique). Les archives antérieures
restent intactes.

`baseline.json` décrit chaque état initial et final, `replays.tar.gz` contient les
replays avec leurs checkpoints, `sources.json` identifie les sources utilisées et
`SHA256SUMS` permet de vérifier les fichiers archivés.
