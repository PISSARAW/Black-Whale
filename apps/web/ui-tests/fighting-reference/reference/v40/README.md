# Référence de commandes · clash-combat-40

Les 96 flux de commandes historiques ont été réenregistrés avec la punition après un coup dans le vide étendue aux quarante combattants. Les prémisses et les commandes d’origine sont conservées. Les checkpoints sont calculés par le moteur de production. Les 96 empreintes finales correspondent à la v39.

Les archives antérieures sont conservées. `baseline.json` indique la provenance et les empreintes des commandes, `SHA256SUMS` protège l’archive et `sources.json` décrit le périmètre TypeScript de combat utilisé pour la mesure.

Les tests `whiffPunish.test.ts` vérifient les ouvertures en déplacement face aux deux gardes et dans les deux orientations. `combatSchool.test.ts` vérifie les démonstrations et leur relecture aux cadences prises en charge.
