# Shizuku · référence de combat

Depuis `apps/web` : `node scripts/check-shizuku-reference.mjs`.

phases et deux orientations, avec les modèles, les gestes et Blinky de production.

l’extraction du sang par la blessure obtenue. Le rejet utilise un objet de fixture.
