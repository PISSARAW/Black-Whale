# Kalluto · référence animée

La page `/ui-tests/kalluto-reference/` utilise le moteur, les figures, les poses
et les effets de production. Elle montre le repos, une coupe d’éventail,
la dispersion et le serpent dans les deux orientations. Le serpent est précédé
d’un véritable marquage par le moteur, sans ajouter de marque à la main.

Depuis `apps/web` : `node scripts/check-kalluto-reference.mjs`.
Le contrôle écrit huit captures et un rapport dans `output/kalluto-reference/`.
