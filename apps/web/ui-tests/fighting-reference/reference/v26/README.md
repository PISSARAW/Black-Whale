# Référence de combat 26

Les 96 flux de commandes originaux, rejoués sous `clash-combat-26` : lot 3 de la
[grammaire de combo](../../../../src/lib/fighting/COMBO_GRAMMAR.md). Hisoka, Chrollo
et Feitan rejoignent Kurapika et Benjamin dans la grammaire à niveaux ; Phinks reste
hors grammaire. Le schéma simplifié retire désormais 10 % aux supers, contre 20 % dans
`v25`. 80 états finaux changent. Les archives antérieures restent intactes.

`baseline.json` décrit chaque état initial et final, `replays.tar.gz` contient les
replays avec leurs checkpoints, `sources.json` identifie les sources utilisées et
`SHA256SUMS` permet de vérifier les fichiers archivés.
