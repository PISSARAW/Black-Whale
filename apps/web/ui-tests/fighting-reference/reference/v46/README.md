# Référence de commandes · clash-combat-46

Le défenseur peut reprendre la main après une relance directionnelle. Il peut reculer en l’air, attaquer ou accélérer sa descente avec Bas + Garde. La garde s’active au sol. La sortie prend effet à partir de la première frame où le défenseur est libre.

Les 96 flux historiques ont été réenregistrés à partir de leurs prémisses et commandes d’origine. Les états finaux correspondent à v44. `SHA256SUMS` vérifie l’archive et `sources.json` identifie le code utilisé pour la simulation.
