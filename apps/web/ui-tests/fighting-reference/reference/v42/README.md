# Référence de commandes · clash-combat-42

Les combattants jouables disposent de quatre fins directionnelles après deux coups légers confirmés. Les commandes normales conservent leurs propres cancels. Les techniques proposées depuis cette chaîne passent par leurs contrôles habituels d’aura, d’équipement et de préparation.

Les 96 flux de commandes historiques ont été réenregistrés avec leurs prémisses et leurs paquets d’origine. Le fichier `baseline.json` conserve leurs empreintes et leur provenance. `SHA256SUMS` vérifie l’intégrité de l’archive et `sources.json` décrit les sources de combat utilisées.
