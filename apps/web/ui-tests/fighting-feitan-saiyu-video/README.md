# Feitan contre Saiyu — vidéo des corrections

`node apps/web/scripts/render-feitan-saiyu-combat.mjs` exporte une démonstration
sonorisée de 16 secondes dans la chambre funéraire des princes, à 1280 × 720 et
30 i/s. Les sept chapitres couvrent la
garde emblématique, les rémanences et occultations, les attaques au sabre, le
parapluie et sa pointe, la blessure, Pain Packer puis Rising Sun.

Le script refuse l'export si un de ces états n'a pas réellement été traversé.
Le MP4, les captures et le rapport sont dans `output/clash-feitan-saiyu-video/`.
