# Référence de commandes · clash-combat-43

Kurapika et Hisoka peuvent convertir leur relance directionnelle confirmée avec un léger aérien ou une technique. Dowsing Whip et Bungee Gum conservent leurs coûts et leurs conditions d’utilisation. La variante Bungee Gum d’Hisoka exige un lien sélectionné sur l’adversaire.

Les 96 flux historiques ont été réenregistrés à partir de leurs prémisses et paquets d’origine. `baseline.json` conserve leurs empreintes, `sources.json` en décrit la provenance et `SHA256SUMS` vérifie l’intégrité de l’ensemble.

Les 96 états finaux correspondent à la référence v42.
