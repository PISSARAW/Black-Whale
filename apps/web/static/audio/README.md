# Melody's concert

`melody-concert.mp3` is the original three-minute interpretation used by the
chapter 383 concert reconstruction. The project owner supplied the source WAV
on 2026-11-12; its final silent tail is trimmed to the tour's canonical
three-minute duration.

It is the only recorded audio asset aboard the tour. Playback is routed through
the shared Web Audio graph in `src/lib/audio/ambient/melodyConcert.ts`.
