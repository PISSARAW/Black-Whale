# Hisoka · Attaches multiples

La fixture utilise les commandes du moteur pour préparer trois liens, monter
vers le plafond réel du casino et rappeler puis relancer la même carte.
Le contrôle `node apps/web/scripts/check-hisoka-network.mjs` vérifie les objets,
le rendu de chaque lien, les coordonnées finies, le choix du membre et la largeur
mobile. Les captures et le rapport vont dans `output/clash-hisoka-network`.
